# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within AI Privacy Gateway, please send an email to security@example.com or open a private security advisory on GitHub.

Please include:
- A description of the vulnerability.
- Steps to reproduce or proof-of-concept payload.
- Potential impact and affected endpoints.

We will acknowledge receipt within 48 hours and work with you to coordinate a disclosure timeline.
